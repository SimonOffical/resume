\datedsubsection{\textbf{基于数据驱动的时频电磁数据自适应融合反演}}{2024.9 - 至今}

  \item \textbf{方法（Linux 环境，PyTorch）：}
  \begin{itemize}
    \item \textbf{深度学习驱动先验建模：} 利用 ResNet1D 构建可信度评估网络，将传统经验加权转化为数据驱动的逐层约束。
    \item \textbf{自适应融合：} 设计聚焦融合机制，在浅层引入 FDEM 先验，深层依托 TEM 响应，结合 MGS 聚焦约束增强界面锐度。

\datedsubsection{\textbf{高鲁棒性多模偏心补偿线圈设计}}{2026.3 - 至今}
\begin{itemize}[parsep=0.2ex]
  \item \textbf{挑战：} 解决小回线探测中一次场耦合干扰（PFCI）导致的接收机饱和问题，以及传统结构对机械装配精度要求过高的问题。
  \item \textbf{创新：} 提出"Bucking 对消 + 接收端对称偏心"双级补偿拓扑，将接收线圈迁移至低梯度区，从原理上降低对机械公差的敏感度。
  \item \textbf{成果：}
  \begin{itemize}
    \item 蒙特卡洛仿真显示，该结构将一次场泄漏均值降低 83.43\%，位置偏差敏感度（MID 标准差）缩小 72.44\%。
    \item 实测一次场泄漏率仅 0.65\%（传统 bucking 结构 15.88\%，偏心结构 1.09\%），铁磁目标定位平均相对误差 4.52\%。
    \item 撰写论文一篇，已投稿至 \textit{IEEE Trans. Instrum. Meas.}（JCR Q1），审稿中（Under Review）。
  \end{itemize}
\end{itemize}

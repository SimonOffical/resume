\datedsubsection{\textbf{ResNet1D-MGS时频电磁自适应融合反演}}{2024.9 - 至今}

  \begin{itemize}

    \item \textbf{自适应融合：} 设计聚焦融合机制，在浅层引入 FDEM 先验，深层依托 TEM 响应，结合 MGS 聚焦约束增强界面锐度。
  \end{itemize}
  \item \textbf{成果：} 完成并行 Jacobian 计算模块开发，合成模型验证表明该方法在界面恢复精度上显著优于传统方法；拟投 \textit{IEEE Trans. Geosci. Remote Sens.}(JCR Q1)。
\end{itemize}
\datedsubsection{\textbf{高鲁棒性多模偏心补偿线圈设计}}{2026.1 - 2026.6}
\begin{itemize}[parsep=0.2ex]
  \item \textbf{挑战：} 小回线探测中的一次场耦合干扰（PFCI）会淹没微弱二次场并引入系统误差；传统补偿结构虽可抵消一次场，但补偿效果受线圈位置与尺寸偏差影响显著，对机械装配精度要求较高。
  \item \textbf{创新：} 提出"Bucking 对消 + 接收端对称偏心"双级补偿拓扑，将接收线圈迁移至低梯度区，从原理上降低对机械公差的敏感度。
  \item \textbf{成果：}
  \begin{itemize}
    \item 蒙特卡洛仿真显示，该结构将一次场泄漏均值降低 83.43\%，位置偏差敏感度（MID 标准差）缩小 72.44\%。
    \item 实测一次场泄漏率仅 0.65\%（传统 bucking 结构 15.88\%，偏心结构 1.09\%），铁磁目标定位平均相对误差 4.52\%。
    \item 撰写论文一篇，已投稿至 \textcolor{publication}{\textit{IEEE Trans. Instrum. Meas.}（中科院二区），\textbf{审稿中（Under Review）}}。
  \end{itemize}
\end{itemize}
\datedsubsection{\textbf{TEM 瞬变电磁发射采集与多测点联合降噪系统}}{2026.5 - 2026.6}
\begin{itemize}[parsep=0.2ex]
  \item \textbf{项目仓库：}\faGithub\ \url{https://github.com/soyoAgain/TEM-Prospector}
  \item \textbf{采集系统：} 基于 NI PXIe-4309/6361 搭建 TEM 发射--接收实验链路，开发由 PySide6、NI-DAQmx 与 SSH 驱动的测量软件，实现脉冲参数化控制、发射电流/接收信号同步采集（250 kS/s）、实时监测及实验数据自动回传。
  \item \textbf{多测点信号处理：} 基于 Block Hankel 矩阵、随机化截断 SVD 与对角平均实现 MSSA 联合降噪，利用不同测点 TEM 响应的共享低秩结构抑制非相干噪声，增强晚期弱二次场信号的可辨识度。
  \item \textbf{科研支撑：} 构建按项目、测点与采集参数组织的标准化数据管理流程，形成可用于 TEM 反演、数据驱动先验学习及模型泛化验证的实测数据基础。
\end{itemize}
